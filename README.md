# Nyaniso Khoza — Personal Portfolio V1

Executive Dark / Glass portfolio starter.

## Run locally

No build tools are required for this version.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For the most reliable local testing, run a simple local server:

```powershell
python -m http.server 8000
```

Then open:

`http://localhost:8000`

## Folder structure

- `index.html` — main portfolio page
- `css/style.css` — complete visual styling
- `js/script.js` — navigation, scroll state and reveal animations
- `assets/images/` — future project/profile images
- `assets/icons/` — future icons
- `assets/documents/` — drop `Nyaniso-Khoza-CV.pdf` here to activate the Download CV button
- `projects/` — future project-specific assets/content
- `CHANGELOG.md` — version history
- `CONTENT-TO-ADD.md` — information still required

## Download CV

A floating "Download CV" tab sits on the right-hand edge of the page (bottom-right pill on mobile). It links to `assets/documents/Nyaniso-Khoza-CV.pdf` and will work as soon as that file is added — no code changes needed.
